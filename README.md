# 🚴‍♂️ Sistema de Recomendación de Rutas para Ciclistas

## 📌 Descripción
Sistema basado en ciencia de datos que analiza métricas de entrenamiento para recomendar rutas adecuadas según el nivel del ciclista.

## 🎯 Objetivos
- Analizar datos históricos de entrenamiento
- Clasificar usuarios según rendimiento
- Recomendar rutas según dificultad

## 🗄️ Datos utilizados
- Distancia
- Tiempo
- Velocidad promedio
- Elevación
- Tipo de actividad

## 📊 Enfoque de Ciencia de Datos
- Limpieza de datos
- Cálculo de métricas
- Clasificación de usuarios
- Reglas de recomendación

## 🛠️ Tecnologías
- Python
- Pandas
- SQL
- Jupyter Notebook

## 📁 Dataset
Dataset obtenido de Strava/Kaggle.

## 🔄 BPMN del proceso
1. Registrar entrenamiento
2. Almacenar datos
3. Procesar métricas
4. Clasificar usuario
5. Generar recomendaciones
